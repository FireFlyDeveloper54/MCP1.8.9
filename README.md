# Minecraft 1.8 Premium modification Source

本仓库是一个基于 **Minecraft 1.8.9** 版本的 **MCP (Minecraft Coder Pack)** 客户端开发项目。

## 项目概述

- **Minecraft 版本**：1.8.9
- **构建工具**：MCP 官方工具链
- **用途**：个人客户端开发、模组开发
- **环境**：JDK8≤

 ## 本项目相较于原版的改动

  - 加入了Optifine和BetterFPS（已移除Forge反射调用）
  - 重写了部分渲染减少性能占用
  - 几乎恢复了所有被混淆的字段
  - 移除了Him
